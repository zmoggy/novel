CHARACTER PORTRAITS FOLDER
===========================

Place your character portrait images in this folder with the following names:

1. phainon.png - Phainon (white/silver hair character with weapon)
2. mydei.png - Mydei (red/blonde hair character)
3. danheng.png - Dan Heng (dark hair character with horns)
4. aurelia.png - Aurelia (golden-haired elegant character)

Image Requirements:
- Format: PNG (recommended) or JPG
- Recommended size: 300x400 pixels or larger
- The images will be displayed in the dialogue box portrait area (180x200px)
- Images should show the character from chest/waist up for best results

The dialogue system will automatically:
- Load these images when NPCs speak
- Fall back to drawn sprites if images are not found
- Scale images to fit the portrait area
